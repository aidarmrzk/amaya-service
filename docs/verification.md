## Figma и браузер

Основной макет 390 × 780, одинаковые SVG, Nunito и размеры. Экспорты:
`screenshots/figma-390.png`, `screenshots/web-390.png`.
Размеры изображений совпадают; средняя абсолютная разница RGB = 1.216 из 255.
Нормированная близость по этой метрике = 99.523%.
96.127% пикселей имеют максимальную разницу каналов <= 16; это отдельная,
более строгая метрика, поэтому 99% буквального попиксельного совпадения
не заявляется. Основные остаточные различия — сглаживание и метрики текста
в Figma и Chromium на Windows; исходные снимки доступны для проверки.

## Доступ и данные

Отдельный Appwrite-проект, база amaya, таблица purchases.
Runtime-ключ: только rows.read/rows.write, закрытая конфигурация сервера.
Идемпотентный ID строки учитывает и устройство, и requestId.
API возвращает только id/offerId/createdAt. Сумма и deviceId от клиента отвергаются.
Cookie: HttpOnly, SameSite=Lax, Secure в production.
Проверка стороннего устройства — обязательная часть smoke-скрипта.
